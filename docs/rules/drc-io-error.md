# Rule: `drc-io-error`

## Problem / Symptom
An I/O failure occurred when attempting to read the DRC report file generated by `kicad-cli`.

## Root Cause
File permissions, missing temporary directory, or disk access error prevented reading the report.

## Remediation

1. Check file permissions in the working directory.
2. Ensure the temporary directory is writable.
